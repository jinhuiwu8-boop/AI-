## 本地开发版

可在电脑上直接操作手机界面：[手机端操作测试台](http://localhost:3213/mobile-test)。启动用`tools/start-mobile-test.ps1`，使用独立data/mobile-test保存测试结果，具体用法见[手机端操作测试说明](手机端操作测试说明.md)。

手机现按旧图及确认修改使用三底栏、白卡、客户弹窗和纵向开单；电脑版保留新版。最新源码及验证见[W4客户退货交付](docs/开发执行/W4_客户退货/00_本轮修改交付.md)。新退货只选客户商品，散瓶按历史成交箱价除瓶数到角，目前可报价预览，保存待Q00数量策略。当前142项Node与11项Python通过；不代表新正式保存闭环或目标设备验收。W3布局和W2实现保留历史记录。

最新修改规则见[手机开单与工程看板调整](docs/功能逐页梳理_2026-10-30/10_手机开单与项目进度调整_v0.2-r6.md)：手机开单输入仅文字/语音、预览移至核对保存区、明细紧凑；工程进度继续保存在项目文件看板，不进入经营页面。

已进入W2真实实现，运行入口为`tools/start-local.ps1`，打开本机 http://127.0.0.1:3210 。运行需要Node24及支持Pillow、reportlab的Python，启动脚本优先使用本机已配置的依赖运行时，无需联网安装。单据生成器可用BILLING_PYTHON指定其他Python路径。

当前可验证客户商品维护、价格保存/恢复、销售、更正冲回、原单部分退货、正式PNG/变量PDF、日月统计、60秒封单、设备推理租约/候选人工转单及独立打印状态。101项Node与11项Python检查通过，局部浏览器开单/部分退货/统计已实测。详情见[W2开发交付](docs/开发执行/W2/00_W2开发交付与工作口.md)。页面使用合成样例；本地开发会话、浏览器下载和打印排队不作为生产授权、原生相册或真实出纸验收。数据保存在data/且由Git忽略。

最新业务补充见[历史更正价沿用及W1范围](docs/功能逐页梳理_2026-10-30/08_历史更正价沿用与W1开发_v0.2-r4.md)。

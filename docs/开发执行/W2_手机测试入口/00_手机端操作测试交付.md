# 手机端可操作测试入口

2026-10-31；w2-mobile-test-v0.2.1。依据用户澄清“手机端的操作界面模块，让我可以在电脑上测试手机端的使用情况”，在已实现页面上增加可自行操作的固定手机窗口，不替用户自动执行演示。

入口：http://localhost:3213/mobile-test 。运行 tools/start-mobile-test.ps1 或 node src/server.mjs --mobile-test；默认使用独立data/mobile-test和端口3213，只监听本机。数据不清除、不进Git，测试服务和原data/local分开。

## 变更及归属

- A03新增web/mobile-test.html、mobile-test.mjs、mobile-test.css。左侧八模块、真实390/430×860手机iframe、适应窗口/100%显示；模块只切子窗口hash，不重新载入页面。手机内pushState/replaceState导航由只读观察同步菜单。原app/index/style未修改。
- ROOT增加静态白名单和CSP。仅显式/?mobile-test=1可被同源嵌入；原业务页仍禁止嵌入，壳只允许同源frame。没有改变API权限。
- ROOT将本地会话cookie名称按工作区区分，避免同一浏览器打开不同端口的开发/测试库时互相覆盖。随机会话值、HttpOnly、SameSiteStrict、CSRF和设备独立鉴权保留。
- A07独立检查新增5项HTTP，ROOT另跑原有11项HTTP/安全回归。均通过，不重复声称全量W2已在本轮重新运行。

## 实际验证

新增5项及静态核查详见[A07验收](A07_验收.md)；原11项回归日志见[HTTP与安全回归](验证/原HTTP与安全回归.tap)。真实PNG持久、重复提交、SQLite重启、会话隔离、嵌入CSP和设备越权负例均有记录。源代码身份见[源码清单](验证/源码清单.json)，不是Git提交。

ROOT在IAB实际操作本入口：

1. 点击父菜单进入手机客户维护，在iframe填写“手机端自测客户”和测试地址。
2. 切工作台后再回客户维护，两个输入值保留；在iframe点击保存返回稳定ID和version1。
3. 刷新父页面后再次打开客户维护，保存的客户仍可在列表查到。
4. 在手机底部点击客户价格，左侧菜单同步到客户价格；切390视口后iframe宽度确为390。
5. 在客户表单填临时草稿，切100%显示和390宽度，草稿保留；清除未提交草稿后进入图片开单，保留可操作页面供用户测试。

[操作测试台截图](验证/手机端可操作测试台.jpg)是ROOT真实浏览器证据；不冒称A07独立浏览器或Mate60实机验收。测试数据只增加一个客户，没有自动创建销售或打印回执。未修改原用户02文件/快照，没有Git上传或生产部署。

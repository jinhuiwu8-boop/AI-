# A03 电脑手机操作界面入口回交

2026-10-31。依据本轮明确设计：提供用户自己点击、填写和保存的手机界面模块，不代操作、不自动演示、不以截图代替可操作入口。

## 文件与职责

本次仅新增：

- `web/mobile-test.html`：左侧八模块、当前模块、手机窗口、390/430 宽度选择、独立打开和数据范围提示。
- `web/mobile-test.mjs`：同源 iframe 模块切换、菜单同步、固定真实视口及外层适配。
- `web/mobile-test.css`：独立测试壳样式；所有缩放等级在外部 CSS 中定义。
- 本回交。

没有修改 `web/app.mjs`、`web/index.html`、`web/style.css` 或业务源码。ROOT 负责 `/mobile-test` 与资源路由、仅手机测试查询入口允许同源嵌入的 CSP、固定独立数据后端及启动脚本；A07 独立验收单列。

## 实际交互

| 项目 | 当前行为 |
| --- | --- |
| 模块 | 工作台、销售订单、图片开单、待核订单、客户价格、客户与商品、打印任务、项目进度，仅已有八项 |
| 手机页面 | 同源 `/?mobile-test=1#home` 的真实 app；并非复制页面或演示图片 |
| 电脑操作 | 鼠标可直接在 iframe 内填写、点击、核对和保存；窗口内部滚动，保留真实手机底部导航 |
| 真实视口 | 390×860 或 430×860，选择宽度时更新 iframe 宽度属性与外部 CSS 类，不重新加载 |
| 窗口适配 | 默认“适应窗口”，手机真实视口保持不变，只将外层壳按外部 CSS 预设比例缩放；另可选“100% 大小”，外层滚动、顶部对齐，不裁掉手机顶部；两种方式均显示真实尺寸和显示比例，不重载或清草稿 |
| 左侧切换 | 只改同源 iframe 的 hash，不改 src、不 reload、不调用新业务接口，因此不因测试壳切换而重建手机页面 |
| 手机内跳转同步 | iframe load 后监听 hashchange/popstate；对 app 的 pushState/replaceState 另作 350ms 同源 URL 只读观察，菜单与当前模块随之同步 |
| 安全访问 | 跨窗口读取和事件绑定均有 try/catch；检查同源、根路径及 mobile-test 查询值，不对未知外部页面强制重载 |
| 独立打开页面 | 当前模块链接指向同源手机入口，由普通独立浏览器窗口的实际宽度响应布局，不强制手机宽度；文案与链接提示明确这一点。独立页面共享已保存测试数据，不复制尚未保存的内存草稿 |
| 数据提示 | “当前本地测试数据会保存”，点击保存会写当前测试库、刷新后保留；不硬称任意部署的 /mobile-test 都自动隔离 |
| 设备边界 | 明确企业微信、Jetson、原生手机能力及佳能实纸仍待实际接入，没有假识别/假出纸按钮 |

iframe 采用 `referrerpolicy="same-origin"`，未加 sandbox；嵌入权限由 ROOT 的服务端 CSP 决定，避免壳自行限制真实页面下载能力。页面没有内联脚本、内联样式、内联事件属性、数据重置按钮或自动引导业务动作。

## 已做验证

- `node --check web/mobile-test.mjs` 通过。
- Python HTML 解析与源码断言通过：八模块准确、仅一个同源真实 app iframe、初始 430×860、无 sandbox；脚本全部外部加载，无内联样式和事件属性。
- 静态断言：壳没有 fetch 业务调用、没有写 frame.src、没有 reload，没有 innerHTML；390/430 固定视口与 20% 至 100% 外部缩放类完整。
- A03 未调用任何浏览器自动化，未替用户填写或保存订单。HTTP/CSP、实际 iframe 操作、宽度适配和下载由 ROOT/A07 后续验证；本回交不冒充浏览器验收通过。
- ROOT 反馈已在浏览器实际打开可操作 iframe，指出适应窗口下字偏小，因此补充“适应窗口 / 100% 大小”选择；100% 模式使用现有 scale-100 和外层顶部对齐滚动，不改真实视口。最后语法与静态检查通过后冻结本轮壳页面，具体保存/导航与独立验收由 ROOT/A07 分别记录。

ROOT 提供的专用启动方式为 `tools/start-mobile-test.ps1` → `node src/server.mjs --mobile-test`，默认本机 3213、固定 `data/mobile-test` 测试目录。测试壳自身不创建、清空或迁移数据库，不上传 Git 或部署生产环境。

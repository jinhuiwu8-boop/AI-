## 独立场景覆盖

| 范围 | 实际验证的不变量 |
| --- | --- |
| 主档和金额 | 未知客户/SKU/单位拒绝，不借他人价；零、负、分数量、NaN、Infinity、字符串、非安全整数及乘积溢出拒绝且无部分写入 |
| 授权与幂等 | 非老板、已失效、伪造isBoss不能写；同请求同输入回原结果，异输入/异类型/异actor409，状态不变 |
| 价格与更正 | 手改仍拒绝旧priceVersion；非零更正影响后价；人工明确0价不覆盖常规价；保留历史修订、冲回旧销售再记正确，重复不二次冲回 |
| 恢复和重复价键 | 同一确认/更正中，同SKU单位的多行人工同价只写一价事件，恢复目标仍为确认前100，而非新价110/90 |
| 退货 | 原客户/原行/单位/原价强制绑定；部分退货、重复回执、累计超额、已退数量下限、已退后数量更正净0；不擅自开放已退价格变更及抵扣反向分配 |
| 失败和重启 | 单据替身失败时销售/更正/退货及价格、事件、额度、operation结果全量回滚；真实SQLite重启后幂等结果、后价、冻结单和剩余额度保留 |
| 收单 | 停用来源、危险媒体路径及缺引用拒绝；来源/会话隔离；同ID异内容409；60秒边界、重复不续时、语音产品续时、重启封单不多建任务；不计销或打印 |
| HTTP与PNG | 本地会话、CSRF、Origin、Sec-Fetch-Site、Host、JSON类型/内容、路由允许清单；非法编码400；单据必须已归属且有会话，PNG真实魔数/摘要/历史版本保留 |
| 金融字段版式 | 过长数量/金额不能重叠或被裁成不完整金融信息；列内字号适配仍不足时，真实渲染失败返回503并回滚业务 |
| PrintJournal | 提交意图跨重启保留、进程突然退出后保守待核、outbox断网重试及ACK持久、绑定不可改/每次一份、异结果拒绝、未知不自动重印 |

上表混合了21项独立Node场景及实际重跑的Python6项。变量取值循环覆盖多个负例，不另计成不存在的独立测试数。原W0的41条文字样例没有宣称全部转成41条可执行测试；当前通过数以真实测试运行器为准。

日期：2026-10-31；范围：本地Python标准库日志模块；未接真实打印机或云API。独占新增`src/edge/print_journal.py`、`test/edge/test_print_journal.py`及本文，不修改Node共享存储、订单/销售或台账。

## 接口与worker调用约束

`PrintJournal(filename)`打开本地SQLite（父目录由调用方准备），支持with上下文与close；事务BEGIN IMMEDIATE、WAL、synchronous FULL。错误为JournalError，不进行网络、lp或其他打印调用。

| 方法 | 签名/结果 |
| --- | --- |
| register | `register(attempt_id, *, order_id, revision, document_sha256, copies=1)`；绑定不可变，同内容复用，异内容拒绝；copies必须整数1，revision正整数 |
| begin_submission | `begin_submission(attempt_id)`；仅PREPARED可调用，提交意图事务落盘后才返回；同attempt不可再次提交 |
| record_result | `record_result(attempt_id, *, outcome, queue_id=None, error_code=None)`；outcome为ACCEPTED/UNCERTAIN/FAILED_BEFORE_SPOOL，结果与待回传outbox原子保存；ACCEPTED必须有队列编号；相同结果幂等，异结果拒绝 |
| pending_results | 返回未ACK结果及完整版本绑定、队列ID、结果ID和失败次数；用于重发结果，不用于重发打印 |
| record_delivery_failure | `record_delivery_failure(result_id,error_code)`；持久记录失败次数，不改变原结果；不自动执行传输 |
| acknowledge | `acknowledge(result_id)`；幂等ACK，调用者须先核验云端匹配且持久接收的回执；不是本模块自造云接收事实 |
| recover | 返回potentiallySubmitted、pendingResults、prepared、autoReprint；autoReprint始终空，SUBMIT_INTENT无回执属于潜在已提交，不进入prepared |
| get | `get(attempt_id)`查询持久状态和绑定快照 |

预期worker顺序：登记不可变绑定→校验真实附件/设备/权限→begin_submission持久返回→外部执行一次打印→按真实结果record_result→回传pending_results→验证云ACK后acknowledge。若preflight确定未提交，可从PREPARED记录FAILED_BEFORE_SPOOL；意图后异常没有明确未提交证据必须记录UNCERTAIN或保留SUBMIT_INTENT待核，不能为了重试谎记提交前失败。

SUBMIT_INTENT窗口即使实际尚未执行打印，也保守视为可能已提交；队列查不到不能推出没打印。模块不把ACCEPTED当实际出纸，不提供自动重印/人工出纸伪回执；需要重打时必须由云端授权新attempt、copies=1，订单和销售不改变。

更正前后分别绑定order_id/revision/document_sha256；原attempt不可改为新版本。实际冻结快照、文档文件校验、云端租约及老板权限由后续worker/合同层接入；单独此模块不能证明已经完成这些校验。退货图片不经过本模块转换为正销售。

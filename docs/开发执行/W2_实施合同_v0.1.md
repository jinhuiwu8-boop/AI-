## A01云边服务

导出`createEdgeService({store,now=()=>new Date().toISOString(),leaseSeconds=120})`，DomainError与同步事务沿W1。INFER任务来自state.edgeJobs，WAITING_EDGE为可领取；批次60秒与任务120秒租约是不同概念，后者为本地可配置技术默认，不声称用户指定。

方法：

- registerDevice({operationId,name,capabilities:['INFER'|'PRINT']},bossActor) → {device:{id,name,capabilities,active,createdAt},token}。只存tokenHash，不在后续listDevices返回token或hash。只有老板可创建/撤销。
- listDevices()；revokeDevice({operationId,deviceId},bossActor)；authenticate({deviceId,token},capability) → {deviceId,capabilities}。每次领取/续租/结果都重新查有效设备；撤销立即拒绝。
- claimInference({deviceId,token}) → {job:null}或{job,leaseToken,leaseUntil}。条件领取唯一任务，过期识别可重排，原租约不再有效；任务只含自身批次受控原文与媒体元数据，不串来源附件。
- renewInference({deviceId,token,jobId,leaseToken})；completeInference({deviceId,token,jobId,leaseToken,result})。result为{customerId:null或已存在ID,items:[{skuId:null或已存在ID,productName?,unit:null或合法单位,quantity:null或正整数}],issues:[string]}，限制100行、字符串长度，不接受价格字段为权威；未知ID或歧义不自动建主档。初版可对非法ID拒绝，null代表明确待人工补。
- 成功回传规范摘要、candidateVersion字符串，job.status='AWAITING_REVIEW'，job.candidate保存受控结果；同已授权设备重传同结果回原成功，异结果409；晚到旧租约不能覆盖已人工核对。不能写订单/价/销售。

不把这个服务称真实Jetson模型。POST云边接口由ROOT暴露Bearer token+X-Device-Id；老板cookie和设备token权限分开，打印运输仍由独立打印服务处理，不套用识别超时重排。

## A02主档、匹配和核对转单

新增`createMasterDataService({store,now})`（src/business/masters.mjs）并从index导出：

- saveCustomer({operationId,id?,expectedVersion?,name,address,contact?,phone?,aliases:[]},bossActor)。新增稳定ID，允许同名，用地址区分；版本冲突409。保存联系人与客户电话不能顺便授权转单人。别名trim/去重，保留不同客户同别名为歧义，不悄悄覆盖。
- saveProduct({operationId,id?,expectedVersion?,name,units:['箱','瓶'],bottlesPerCase},bossActor)。正整数包装，停用/历史删除不在本切片开放。修改包装只影响后续派生价，冻结历史不变。
- matchCustomer(text) → {candidates:[{customerId,name,address,reason}],ambiguous}；优先正式名精确和别名精确，多个精确保持歧义；可做受控包含候选，不伪造模型置信度，最多5个。
- queryOrders({customerId?,type?,from?,to?})、getPeriodStats({period:'day'|'month',date:'YYYY-MM-DD'或'YYYY-MM'})。时间按Asia/Shanghai，from包含to不含；非法日期拒绝。金额按真实销售事件时间与冲回/退货分列，不能按当前订单重算历史事件。

W1 createSale增加可选sourceJobId/candidateVersion，只有显式checked人工确认才可调用；同事务检查job仍AWAITING_REVIEW且候选版本相同，没有reviewOrderId，成功后置REVIEWED并写reviewOrderId。重复同operationId返回原结果，不同请求再次消费同job拒绝。更正/0价原规则不变。

记录correctionSamples：原候选/模型信息（有则）、人工确认规范客户/商品/数量/单位、job/order/版本、status='RECORDED'，只有存在非价格识别纠错才入样本，重传不多样本。这里只是样本记录，不称真实自动训练完成。不得把一般改价当OCR纠错标签或改全体客户价。

## ROOT打印服务与文件

`createPrintService({store,documentStore,now})`，每次1份。排队引用已确认销售冻结版本，生成真实变量PDF并持久读回；PDF模板坐标标记未现场校准，预览不证明文博实纸对齐。只有变量，不复印固定纸面。纸质退货未扩范围。

方法queue({operationId,orderId},boss)、list()、markSubmitted({attemptId,deviceId,queueId?,outcome},deviceContext)、confirmPaper({operationId,attemptId,printed:boolean},boss)、reprint({operationId,attemptId},boss)。未提交PENDING_DEVICE不能伪称已打印；有提交可能即UNCERTAIN，绝不自动重印。人工确认未出纸或明确提交前失败后才可新建补打，每次一个attempt、copies=1、引用相同冻结版本，不新增销售。更正后旧attempt仍绑定旧版；未提交旧版可标为SUPERSEDED，不覆盖文档身份；潜在已提交必须先人工检查。

实际worker、CUPS/iP110未连接时页面显示等待设备，测试回执只用于脱敏隔离测试，不给用户一个假“打印成功”按钮。设备结果必须经已授权打印设备身份校验，老板不能用普通网页消息冒充设备回执。

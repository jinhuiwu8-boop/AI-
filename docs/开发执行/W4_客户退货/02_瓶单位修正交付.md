# W4.1 退货瓶单位修正

2026-11-03。用户指出退货最小单位是瓶、现有页面只见退箱。本轮已修正退货默认值及单位可发现性；未改后端报价、正式保存数量政策或已有数据。

原因为初始/新增/换商品按商品单位数组的第一个合法值选择，现有数组箱在前；折叠下拉使散瓶不明显。现在优先合法瓶单位，退货常显“瓶（散瓶） / 箱（整箱）”两个按钮，最少1瓶，数量标签显示当前瓶/箱。销售和更正继续原下拉及原单位顺序。单位切换沿用清价、清包装确认、取消总核对和重新报价的防竞态流程。

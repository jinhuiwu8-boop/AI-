# A06 冻结PDF与人工打印状态回交

2026-10-31；实现版本w2-local-v0.1；依据contract-w2.1及ROOT本轮差量。ROOT明确移交`src/printing/`、`test/printing/`后由本工作口实现；共享server、documents、schema和工程进度仍由ROOT独占。

## 已实现的本地能力

`src/printing/index.mjs`导出`createPrintService({store,documentStore,now,authenticateDevice?,leaseSeconds=120})`。老板排队、人工验纸、补打及设备领取/回执均使用真实SQLite事务。可选authenticateDevice用于整合身份服务，每次设备操作仍在当前事务状态内校验有效PRINT设备及token摘要，撤权立即失效。完整设备token、打印运输token均不保存到操作表、状态或证据。

方法及返回：

| 方法 | 输入/结果 |
| --- | --- |
| queue(input,boss) | `{operationId,orderId}`；返回受控attempt。W1纸质单自动创建的未提交占位沿用同一attempt生成PDF，不另建销售。已有PDF的pending用新operation重排返回409 PRINT_PENDING；同operation原样重试回原结果 |
| list() | 返回受控attempt数组，去掉leaseTokenHash、receiptSignature |
| claimPrint(credentials) | `{deviceId,token}`；返回`{attempt,leaseToken,leaseUntil}`或`{attempt:null,reason?}`。未校准返回CALIBRATION_REQUIRED原因，不能提交 |
| readableAttempt(input) | `{attemptId,deviceId,token,leaseToken}`；只允许本设备未过期SUBMIT_INTENT租约获取受控PDF元数据。用于ROOT设备PDF下载路由 |
| markSubmitted(input,deviceContext) | input为`{operationId,attemptId,deviceId,leaseToken,outcome,queueId?}`，context必须含可信设备ID与原token。SPOOLER_ACCEPTED必须有真实非空queueId；也接受UNCERTAIN和FAILED_BEFORE_SPOOL |
| confirmPaper(input,boss) | `{operationId,attemptId,printed:boolean}`；只可处理SPOOLER_ACCEPTED/UNCERTAIN，结果为PAPER_CONFIRMED或PAPER_NOT_PRINTED |
| reprint(input,boss) | `{operationId,attemptId}`；只允许PAPER_NOT_PRINTED/FAILED_BEFORE_SPOOL，生成一份、同冻结版本及同PDF的子attempt，不重新计销 |
| expireClaims() | 返回`{uncertainCount,attemptIds}`；过期或旧缺租约SUBMIT_INTENT仅转UNCERTAIN，不重排 |

PDF由ROOT的documentStore.savePaper生成并持久读回，A06只接收受控PDF元数据。引用销售对应的冻结revision，保存snapshotSha256；attempt.document、documentId、documentSha256一致，替换W1旧PNG引用。已有非PDF文档只允许尚未提交时从冻结版本补齐，潜在已提交旧任务不能补造文档。

## 防重复及人工边界

设备领取即标记SUBMIT_INTENT，因为领走后可能已经交给打印机；运输租约到期不能像识别任务那样重新派发。打印人仍需实际检查纸张。未提交PENDING_DEVICE不能人工假确认出纸；锁定未知、到期、撤权与错误设备回执，避免迟到请求覆盖人工结论。

设备同回执重复不覆盖结果，不同回执/同操作异内容409。排队、验纸和补打各有操作幂等；同一补打父attempt只生成一个直接子attempt，多次失败需从最新子attempt继续确认/补打。queue不能绕过补打入口。旧W1 QUEUE_PRINT签名明确返回LEGACY_PRINT_OPERATION 409；新操作只补齐原占位，不另加重复任务。

每次copies固定1，补打复用原PDF和revision，不增加销售、价格或订单。更正后未交设备的旧版可SUPERSEDED并生成最新冻结版PDF；旧版存在SUBMIT_INTENT/SPOOLER_ACCEPTED/UNCERTAIN时先拒绝新排队，须先人工确认。旧PDF身份保留；过期旧版本也不能借补打重新打印。

实际savePaper返回calibrationStatus=UNVALIDATED，因此真实PDF当前仅预览，设备claim和提交都被阻止。测试使用明确的合成VALIDATED metadata验证状态机，不能据此宣称130×190毫米实纸套打已通过。未连接CUPS/iP110、未发送真实打印任务。

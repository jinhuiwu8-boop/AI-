## 保留并补强的处理

- W1 提交未知时保留同一 operationId 与原 payload，阻止新写操作，重试原请求；服务端明确拒绝才释放。正式写成功后的汇总读取失败不会误判写失败。
- 行取价、价格编辑器、bootstrap、查单、统计、打印列表和候选读取都对迟到请求作保护；取价期间的人工价格与明确 0 价优先，不被旧报价覆盖。
- 客户、商品、单位、数量、价格、抵扣、抹零、备注、开单方式与 0 价确认等关键编辑均重置人工核对。更正保留 lineId/expectedRevision，非零更正价沿用规则不改。
- 页面路由改为同步维护 route、详情 id 与 URL hash。ROOT 集成交互发现的“销售成功仍留 #create，按原单退货无反应”已修复；销售成功用 replaceState 保留 #orders 详情与成功提示，后续退货/更正立即进入 #create。
- 前端乘积/合计用 BigInt 中间值，超出安全整数范围显示待服务端校验。正式金额、冲回、计销、防超退和权限仍由云端业务服务负责。
- 项目进度继续六阶段状态节点，需求单独记录，不折算开发完成率；无内联宽度或外部脚本/字体依赖。

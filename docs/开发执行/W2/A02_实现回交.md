# A02 W2主档、识别核对转单与时段统计回交

2026-10-31；本地代码切片`w2-business-v0.1`；依据`contract-w2.1`。实现与模块验证已回交ROOT，独立验收及整版进度由A07和ROOT登记；本文不宣称云端生产、真实模型训练、手机或打印机验收完成。

## 已实现

- `src/business/masters.mjs`新增`createMasterDataService({store,now})`，由`src/business/index.mjs`导出。`saveCustomer`、`saveProduct`仅有效老板可写，沿用SQLite同步事务与跨服务共享幂等表。
- 客户稳定ID，新增版本`'1'`；修改携`id/expectedVersion`且版本精确匹配，成功递增字符串版本。旧W1主档缺版本按`'1'`处理。允许同名，以地址及返回候选区分；姓名/地址必填，联系人、电话和别名可空，别名trim和去重。保存电话不会新增转单来源授权。
- 商品允许箱/瓶非重复单位，每箱瓶数必须为正安全整数。包装变化使未来派生瓶价及价版本变化，原单客户名、地址、商品名、价格与修订快照保持冻结。
- `matchCustomer(text)`先返回正式名称/别名精确候选，多个精确匹配保留歧义；无精确时做受控包含匹配。最多显示5项，截断前判断歧义，无模型置信度、无自动建主档。
- `queryOrders({customerId,type,from,to})`返回深拷贝，客户、销售/退货和时间筛选；按确认创建时间倒序。日期边界遵循北京时间，`from`含、`to`不含；也接受带时区的ISO完整时间。筛选使用订单创建时间，财务统计使用实际销售事件时间。
- `getPeriodStats({period:'day'|'month',date})`读取真实`SALE/REVERSAL/RETURN`事件，按北京时间日/月边界汇总，不拿当前订单内容回算历史日。`saleGrossCents`为期间正向销售事件，`reversalCents`为冲回正值，`salesCents=正向销售-冲回`，`returnCents`为退货正值，`netSalesCents=销售-退货`；应收按同一事件符号汇总。返回事件数和该期间出现正向销售/退货事件的独立订单数，修订销售事件可能来自以前创建的订单。兼容W1已有统计字段；业务服务也提供这两个只读方法。
- `createSale`可携`sourceJobId/candidateVersion`。人工checked、有效主档/数量/单位/价格版本仍全部必需；候选有null时可以人工补有效数据再确认。同事务检查任务仍为`AWAITING_REVIEW`、候选版本匹配且未消费，正式文档成功后置`REVIEWED/reviewOrderId/reviewedAt`。同操作重放返回原单，不同操作不能二次消费同一任务。
- 非价格识别纠错才追加`correctionSamples`：原候选、人工规范客户/商品/单位/数量、任务/订单/候选版本、可用模型版本、时间及`status='RECORDED'`。重复提交不重复样本；普通改价、明确0价和单纯调整行顺序不会被标成识别错误。样本记录不是训练完成，未调用真实训练。

## 交付文件及接口

- `test/edge-cloud/edge-cloud.test.mjs`：12项真实Node/SQLite测试，双Worker建立独立连接同时竞争同一个任务。

已实现`registerDevice`、`listDevices`、`revokeDevice`、`authenticate`、`claimInference`、`renewInference`及`completeInference`。所有写操作均在真实`store.transact`内执行，设备授权与有效租约在领取、续租和回传时重新校验；所有业务拒绝使用`DomainError`。

设备可以分别获得INFER、PRINT能力；当前模块只运输识别任务，不替代独立打印服务。设备登记和撤销只接受服务端已验证老板actor。原始设备token和识别租约token只从创建/领取响应返回，状态仅保存SHA256摘要，响应不带摘要。登记操作记录也不保存完整token。

同登记operationId及相同规范内容/操作者重试，不新增设备，也不再次暴露token，返回原设备当前状态及`token:null,tokenAvailable:false,duplicate:true`，并说明首次令牌无法再次读取，未保存时应撤销原设备重新登记。首次返回`tokenAvailable:true,duplicate:false`。这避免把网络重试变成多注册设备或把可重放完整token写入操作表。

## 状态和数据约束

识别领取状态为`WAITING_EDGE → INFER_RUNNING → AWAITING_REVIEW`。租约默认120秒且可配置，与收单60秒封批分开；有效租约可续期，边界到期可由其他授权识别设备重新领取，替换旧租约。未知任务、过期租约、错误设备和错误token均不能写入候选。撤权立即阻止新领取、续租、回传及已成功结果的重放。

`claimInference`返回`{job,leaseToken,leaseUntil}`；无任务时为`{job:null}`。job只包含任务身份、批次/来源/会话、受控客户提示及本批次原文、受控媒体元数据。读取消息时同时匹配sourceId、conversationId、消息ID和消息持久结果的batchId，并与封单批次校验；不返回内部canonical、凭证摘要或其他来源附件。批次不一致时整笔回滚，不能先取得租约再泄露附件。

候选形状固定为`{customerId,items:[{skuId,productName?,unit,quantity}],issues}`。客户/商品只接受既有ID或null，null明确待人工补；单位只接受合法的箱/瓶且与商品主档一致；数量为正安全整数或null。最多100行、100条问题，商品文本至300字符、单条问题至500字符，其他ID和一般设备名至200字符。价格、合计、自动建档命令、checked及其他未定义候选字段严格拒绝，不能借额外字段确认订单或更新客户价。

成功回传生成规范候选摘要和`candidateVersion='inference:<UUID>'`，返回`{jobId,status,candidate,candidateVersion,resultSha256,completedAt}`。同已授权设备、同完成租约、同规范候选重放返回原回执；异候选409。同任务已REVIEWED时，同成功回执重放只读返回，任何不同候选或旧租约不能覆盖人工核对。该模块从不新增订单、客户、商品、价格事件、销售事件、打印尝试或纠错样本。

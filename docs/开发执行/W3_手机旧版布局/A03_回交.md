## 共享呈现接口（供ROOT/A07）

`app.mjs` 导出 `startApp({ presentation })` 与冻结的 `ui` 对象。`body[data-presentation="mobile"]` 导入时跳过电脑自动启动，由 `mobile-app.mjs` 装配后启动；默认电脑文档仍调用同一 `startApp()`。

可选 adapter：

- `routes`：额外的 `mine` 只由手机版注册，不加进电脑版导航。
- `renderNavigation`、`pageHeading`：只负责三底栏、返回和手机标题。
- `renderers.home/mine`：手机工作台和菜单布局。
- `orderIntro/orderResults`：在同一个查单控制器中呈现真实统计和订单卡；筛选、查询代次及订单打开逻辑不重写。
- `decorate`：将原表单调整为手机连续卡片，加入客户列表和P07弹窗；没有复制提交或价格逻辑。
- `usesPeriodStats`：让手机订单页复用同一日月统计读取完成后的渲染通知。

`ui` 只提供状态读取、DOM帮助函数、现有导航/开单/更正/退货动作、现有统计控件、同一估算/summary、取价客户选择、主档编辑与原表单DOM抽出、客户查单和既有 `retryPending`。没有导出新的 HTTP 业务请求或独立价格/计销实现。`request`、`mutate`、`sendPending`、`quoteBillLine`、`loadPrice`、`submitBill`、`saveMaster` 各仍只有一份。

P07网络结果未知的模态边界经ROOT解锁后定点补齐：弹窗内可以点击同一 `retryPending`，沿原 operationId/payload；不会因全局横幅被遮罩挡住而只能刷新恢复。其余未知结果、价版本、迟到报价、明确0价与更正/退货校验仍沿原控制器。

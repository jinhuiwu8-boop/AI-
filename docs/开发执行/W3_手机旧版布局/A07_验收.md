## 实际通过的边界

- **呈现隔离**：`/` 仍返回电脑版模板及 `/style.css`、`/app.mjs`；`/mobile` 返回独立 `mobile.html`、`/mobile.css` 与 `/mobile-app.mjs`。手机模板不带桌面侧栏、桌面导航或桌面 CSS。新增资源 GET/HEAD、MIME、`nosniff` 和白名单路径已实际请求验证。
- **frame 限制**：只有显式 `/mobile?mobile-test=1` 返回 `frame-ancestors 'self'`；桌面 `/?mobile-test=1`、普通 `/mobile`、静态文件及测试壳仍为 `'none'`。测试壳只允许同源 frame，iframe 指向手机入口；跨站请求仍拒绝。此处为 HTTP 头与内容核查，不等于真实 iframe 点击。
- **同一业务合同**：手机同源/Referer 请求上下文下，过期报价版本拒绝且无写入；非零人工调价影响后价；明确 0 元方可开出且不覆盖常规价；相同请求重试只产生同一销售；真实 PNG 可读取，未生成虚假打印或设备结果。
- **更正与退货**：更正保留原/新版本并冲回原销售；随后客户常规价再变化，部分退货仍沿用所选原单版本的成交价；重试只一单，超退和篡改退货价拒绝且原状不变，退货不改后价。
- **既有安全回归**：会话、CSRF、Origin、跨站、Host、路由白名单、编码异常、PNG 摘要及历史冻结、失败回滚、重启持久化等既有 11 项通过；手机入口原 5 项仍验证工作区 cookie 隔离及查询参数不授予设备权限。

## 独立源码与产品核对

A07 实际查看了 P01 工作台、P02 销售订单、P05 我的三张原图，并阅读正式规则及相应人工修改；未宣称逐张目视验收全部 22 图。

手机 adapter 导航明确只有“工作台 / 订单 / 我的”；二级页有返回按钮。独立 CSS 采用浅灰绿背景、白卡、绿色操作按钮和单列表单，并为固定底栏保留安全区。工作台待人工确认、打印需处理在销售卡前，保留图片开单；订单使用列表卡、真实统计及已有筛选；我的为分组菜单，并提供项目进度入口。具体尺寸、滚动、弹窗焦点和手指操作仍以 ROOT 浏览器记录及后续真机为准。

`mobile-app.mjs` 从共享 `app.mjs` 导入 `startApp/ui`，没有独立 `fetch`、销售提交、价格写入或订单金额算法。手机调价、开单、更正、退货、打印继续走共享 controller；新增客户复用已有主档表单及版本处理。共享 app 默认仍自动启动电脑版，只有手机 body 的显式 presentation 标记启用 adapter；“我的”仅作为手机扩展路由注册。

真实能力未接入时保持诚实：锁屏提醒写待 APK 接入，图片/语音入口禁用并说明待接，训练显示纠错样本数量和训练待接，账号显示单设备及系统认证待接；原生相册、企业微信和 Jetson 不因本地页面成功标为已完成。退出的员工角色、操作记录查询界面、企微开关及独立冲突中心未恢复。

客户模态未知结果问题由 A03 自查并经 ROOT 协调修复。A07 已核最终源码：模态内部的“查询 / 重试原请求”直接调用共享 `ui.retryPending`，保留已有 pending 请求及 operationId；未复制提交器或另造请求。该异常路径本轮为源码核查，**未做 A07 独立浏览器断网注入**。

ROOT 另发现草稿预览可能未随局部数量、价格或报价更新。最终定点补丁在共享 `resetCheck` 增加可选 `presentation.refreshBillPreview`，手机实现只替换现有 `.phone-draft-preview`；仍使用共享的估算与汇总函数，不全页重绘、不替换用户输入或复制金额算法。A07 核对数量/单价事件及当前报价回包均沿既有 `resetCheck` 路径触发；桌面没有该可选 hook。此补丁后未重复 HTTP 套件，新增最终静态证据保留了与先前运行的身份差异。

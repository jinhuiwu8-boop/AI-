# W0-A04 兼容验证与单设备恢复方案

日期：2026-10-31；状态：可执行预检方案，所有现场场景尚未执行。输入为正式规则05/06和ROOT本轮最新决定；不向真实号码发验证码，不读取锁屏密码，不运行真设备、不写业务代码。A04持有原生及云端设备授权设计；共享API/schema由ROOT整合。

## 一 最少取证与兼容闸口

由ROOT/Q00统一收集，不由本口直接追问用户：①“关于手机”的完整系统名称与7.0.0.109上下文、型号，可遮序列号/账号；②是否存在APK安装入口或当前同类APK可运行证据；③账号是否已预绑定可验证手机号，只需已/未，不提交号码。开发现场随后记录WebView运行能力、通知/省电设置、APK包名/版本/签名证书指纹、安装结果；不要求为预检批量导出设备隐私。

先验证目标系统能否安装并运行受控签名测试包，再选具体SDK/桥；不能据版本字符串直接判支持/不支持。不具APK运行能力时记录实际提示和系统信息，停止APK成功结论并交ROOT制定替代适配，不把浏览器页面作为APK交付。

## 三 单设备长期授权合同建议

以下为实现方案，不是已完成共享合同：云端每个管理账号仅有一个active_device及递增授权代次；设备密钥/安全存储凭据与会话分离，所有写请求在云端验证设备绑定及代次。手机系统认证本身不能替代云授权。日常长期保持授权，不设置日常固定到期强制重登；会话可滚动续期和撤销，不使用永久不可撤销令牌。

身份状态建议：未授权→待配对/待恢复→当前有效；旧设备转移后为已撤权。恢复备份不得悄悄复活旧授权；云授权历史只留必要后台证据，不恢复员工/操作日志查询界面。令牌、手机号及验证记录按最小化访问，不进Git。

改密：当前有效机向云请求一次挑战→调用系统锁屏认证→使用设备绑定证明提交本次结果及新密码→云检查挑战用途/账号/设备/代次→成功并消费挑战。错误、取消、重放、过期不改密；本地布尔true不能直接成为云认证证据。挑战寿命、失败次数和密码强度由安全技术方案落实，不伪称用户已指定数值。

## 四 正常扫码换机

1. 新机生成自己的设备密钥并申请一次待转移记录；二维码仅携带不含登录令牌的一次配对引用，绑定新设备及本次意图。
2. 当前有效旧机扫码，核对新设备提示，完成系统身份认证并明确同意转移。
3. 云校验旧机仍有效、挑战/二维码未用且未过期，在一个事务/等效强一致操作中激活新设备、递增代次、撤销旧授权与会话并消费转移记录。
4. 新机凭其绑定证明领取授权，旧机立即退出管理；旧机离线再上线、旧令牌和旧通知点击均无管理写权限。
5. 超时/取消不转移。并发扫码、两个新机抢同一次授权只允许一个成功；网络丢回执按原操作ID查询结果，不重新转移。二维码不可复用，具体有效期不猜数值。

## 五 失机/损坏手机号恢复

前置：管理账号已预绑定且完成验证的手机号；用户任填新号码或只输入号码不构成恢复。初次绑定须与已有效管理设备身份及云端账号关联；换绑需验证和留痕，丢号/手机号已注销等例外交Q00集中决策，不用账号密码绕过单设备原则。

1. 新机以设备证明申请恢复事务；服务端仅向账号已绑定号码发送本用途验证，界面脱敏展示目的和设备信息。短信供应商、配额、失败策略及数值待技术选定，本轮不购买不发送。
2. 验证码/验证凭据绑定账号、恢复ID、用途及新设备，云端校验一次性、期限、尝试限制与请求节流；重发不能使旧码与新码都长期有效。错误、跨用途、过期及重放拒绝。
3. 验证成功后，云端以原子操作消费验证并把唯一有效授权转到新机、撤销旧机全部会话。验证成功的中间结果不能成为可任意复制的通用登录票据。
4. 重试查询原恢复结果；两个新机并发验证或旧机同时换机需检查授权代次，避免两台有效。旧机在线和离线恢复联网都必须失效。必要安全告知通过已可用通道展示，不额外引入未经授权的通知服务。

安全验证只使用测试身份/测试号码与受控短信替身；真实号码恢复的现场验证由后续明确环境和有效授权执行。

## 六 交接及验收负例

A01提供真实待办事件、通知去重ID和私有媒体；A03负责按钮/权限失败/进度反馈；A04负责原生桥与云端设备安全；A02确认及销售不因相册/通知/换机重放增加；A06提供冻结单据和持久图片身份；A07独立核验M01—M08及换机/恢复故障矩阵。ROOT冻结接口，A04不自行改schema。

必验负例：伪造系统认证结果、二维码重放、验证码复用/跨用途、恢复后旧token写订单、并发双新机、恢复成功丢回执、已撤权机读私有附件、相册回执丢失、旧通知点击已处理单。敏感操作必要留痕但不展示已退出的操作日志页面。

本轮结论：完成旧壳/候选静态定位、摘要和验证设计；系统类型、APK安装、锁屏通知、系统认证、图库、录音、云撤权及手机号恢复均未实测。没有因缺真机而停止其余预检工作，没有发送验证码、启动业务服务、签名打包或推送代码。

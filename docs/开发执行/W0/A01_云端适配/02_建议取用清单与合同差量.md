## 2. 共享合同字段差量提案

字段名为语义草案，不预设最终URL、表名或JSON键；ROOT定稿后各口实现。

| 合同 | 建议最小语义字段/约束 | 归属与边界 |
| --- | --- | --- |
| 来源身份 | provider、客服ID、可验证稳定来源ID、人工微信号登记引用、授权状态/版本 | A04定义授权，A01验证引用；微信号文本不等身份凭据，不引入员工角色 |
| 消息幂等 | 来源范围＋平台消息ID、云接收时间、平台时间、类型、规范摘要、媒体清单/状态 | A01；相同ID不同摘要冲突需记录，不静默覆盖 |
| 媒体对象 | 对象ID、消息ID、序号、MIME、真实字节数、摘要、时长/尺寸（适用时）、下载状态 | 单个/单条/批次限制分开；缺件显式失败，无首件截取 |
| 收单批次 | 批次ID、来源ID、客户提示、消息序列、最后有效消息时间、截止时间、版本、关闭原因 | A01；60秒静默，与识别租约无关；迟到进入待归属/续单，不改冻结订单 |
| 持久调度 | 工作ID、类型、状态、可用时间、持有者、租约到期、尝试、错误、幂等键 | 适用于客服同步/封单/投递；打印提交后不能沿识别到期重排 |
| 边缘识别 | 任务ID、批次/版本、允许设备、媒体引用、上下文版本、租约、结果schema/摘要/证据 | A05出候选，A02确认；A01只运输，价格候选不能成为业务权威 |
| 业务事件 | 确认/纠错/价格事件ID、订单/冻结版本、事件序号、来源和幂等键 | A02定义；零价不传播、恢复价、新修正与冲回由其规则处理，A01不自行解释金额 |
| 打印运输 | 订单/冻结ID、文档摘要、首打/重打尝试、每次一份、设备、提交标记、队列号、outbox结果ID | A06落盘；A01幂等收件；已提交未知不再派，人工验纸不额外计销 |
| 通知 | 待办事件ID、关联订单/批次、目标授权设备版本、投递/确认状态 | A01持久投递，A04原生，A03落地页；停用旧设备后拒绝读取 |
| 恢复闭包 | schema版本、业务快照点、对象ID/摘要、任务/outbox重放边界、授权恢复行为 | A01归档，A02/A06/A04分别给不变量，A07隔离验证 |

敏感token实际值不进入日志/证据。幂等键必须服务端验证作用域和内容，不接受客户端自称重复就跳过权限或业务校验。结果hash只能辅助防重，不能代替有效租约和内容校验。

## 3. 首批最小可验收切片

1. **M0合同就绪**：ROOT审定运行时/存储/身份/API及基线父项，清楚列源版本和逐文件取用，07业务补充同步。仅此通过不算业务实现。
2. **M1持久入站离线样本**：脱敏回调固定字节→验签/解密→事件持久入队；重复/错误签名/超限/并发同ID分别验证。执行环境必须新隔离测试，不读旧真实库；本W0未执行。
3. **M2客服worker恢复**：合成官方分页替身→消息和媒体保存→游标推进；在领取后、存媒体后、存消息后、游标提交前故障，重启不丢不重复、PROCESSING可回收。替身通过与真实企微接通分列。
4. **M3组单与任务**：可控时钟验证60秒、有效消息续时、重复不续时、切客户、无客户及迟到；TEXT/IMAGE/VOICE分别得到任务；进程停止/重启后截止时间仍有效。语义分类不确定进入人工，不猜自动归属。
5. **M4云边及打印合同**：错误设备/过期租约/重复同结果/重复异结果、附件越权负例；与A06模拟提交后断网、重启outbox对账，打印不重复派。与A02合成同单纸/电子/补打核对销售事件唯一；本口不代签计销模块。
6. **M5目标环境联验**：在另获对应环境授权后，真实企微→阿里云→Jetson→手机及iP110，同一版本验恢复/健康和实纸；A07独立核验，ROOT登记。不能用M1–M4模拟替代此项。

- 媒体官方边界、阿里云现部署/持久卷/进程模型未核实，不能选定多进程SQLite或承诺资源/性能。

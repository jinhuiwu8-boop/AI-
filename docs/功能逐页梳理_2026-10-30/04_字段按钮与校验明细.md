# 字段按钮与校验明细

配套整理版本v0.2-r3，2026-10-31。22张页面方向及用户修改已确认，以最新[07调价更正退货决定](07_调价更正退货与启动确认_v0.2-r3.md)覆盖05/06对应旧未决项。具体未指定的必填条件继续细化，媒体实际限制由技术核验，不重复请求整页批准。

## 一 开单字段

| 字段编号 | 页面字段 | 人工怎样填或查 | 系统怎样处理 | 必填及建议 |
| --- | --- | --- | --- | --- |
| D01 | 开单原内容 | 粘贴文字，或查看微信转发原文 | 保留原始来源，不拿改写内容覆盖原文 | 识别输入可多方式；手工开单可不填 |
| D02 | 图片 | 拍照、选图、预览、删除、重选 | 显示上传/失败及适用限制，原图与识别关联 | 首期支持；按微信上限口径，实际入口/链路由A01/A04核验，见Q17 |
| D03 | 语音 | 按住录音、松开发送、取消、播放 | 保留录音与转写，失败不伪造明细 | 首期支持；按微信时长/大小口径并核验实际链路，权限拒绝允许手填 |
| D04 | 客户名称 | 从主档或候选选择 | 保存稳定客户ID和名称快照，改变客户重新取价 | 正式确认必选 |
| D05 | 客户叫法 | 查看原话或人工维护别名 | 与客户正式名分离；歧义候选待人工选 | 不直接当正式客户新建 |
| D06 | 商品名称 | 搜索SKU选择 | 关联具体规格、口味，带出商品快照 | 每行必须关联主档 |
| D07 | 规格口味 | 核对候选是否对应真实商品 | 不用近似规格替代正确SKU | 来自主档，不凭模型猜 |
| D08 | 数量 | 销售填实际正数量，退货填本次退回的正数量 | 退货模式校验原销售行与累计剩余可退量，防并发超退 | 不开放普通销售任意负数量；支持部分退回 |
| D09 | 单位 | 选箱/瓶等合法单位 | 与SKU合法单位和包装对应，不跨单位直接相加 | 每行必选 |
| D10 | 每箱瓶数 | 查看/维护商品包装 | 未知时不能自动拆箱，派生价写明来源 | 拆箱必需，主档中维护 |
| D11 | 单价 | 销售核对人工价；退货沿原销售成交价 | 普通销售手改确认影响后价；明确0价及退货不更新常规价事件 | 缺价不能猜0；允许人工确认0元（如换盖） |
| D12 | 价源日期和单号 | 查最近确认或客户资料调价 | 显示来源事件和版本，历史不改写 | 只读展示，不让模型编 |
| D13 | 单行金额 | 核对数量乘单价 | 系统算，修改上游字段重算 | 不直接手填绕过单价 |
| D14 | 增加商品 | 点加商品，选SKU并填数量单位 | 新增空行不计销、不记正式订单 | 正式确认前不留无效空行 |
| D15 | 删除商品 | 删除误识别/不需要的行 | 保留人工纠错记录，撤销核对状态 | 删除最后一行后不能确认空单 |
| D16 | 回收类型 | 选空箱/空瓶和对应项目 | 和销售商品分开，使用独立抵扣价 | 空瓶项目规则需明确 |
| D17 | 回收数量 | 填完整个数 | 非负完整数量，按回收价算抵扣 | 不自动使用商品销售价 |
| D18 | 回收抵扣金额 | 核对系统计算 | 与销售货款分列，超过可抵额拒绝 | 抵扣不增加或减少货款销售统计 |
| D19 | 手动抹零金额 | 默认0，必要时填减免金额 | 抹零后算应收，不当客户商品新单价 | 金额范围及统计细节见Q21 |
| D20 | 抹零原因 | 写明原因 | 随订单冻结和审计保留 | 非0时要求原因的建议已写入规划 |
| D21 | 备注 | 填配送、开单说明 | 作为订单备注保存，不参与改价计算 | 是否上纸及长度见模板审核 |
| D22 | 商品合计 | 核对所有行货款 | 独立于抵扣及应收 | 销售货款口径 |
| D23 | 最终应收 | 核对减抵扣/抹零及舍入差额 | 最后四舍五入到0.1元 | 与销售货款分列 |
| D24 | 已核对勾选 | 全部检查后勾选 | 任一关键内容改动后重新核对 | 正式提交前必需 |
| D25 | 确认保存电子单 | 核对后提交 | 正式图片持久保存成功后，销售一次计销，退货一次登记关联退货及销售抵减 | 纯电子不自动打印；重试不重记 |
| D26 | 确认纸质开单 | 核对后提交 | 冻结及一次计销，创建首张打印任务 | 不等待出纸才计销 |
| D27 | 保存相册 | 已确认电子单里点保存 | 原生持久写入成功才反馈成功 | 不另计销 |
| D28 | 本页纸质打印/重新打印 | 电子保存成功后本页独立按钮；同一订单中重打 | 云端建打印尝试，Jetson执行，每次重打1份 | 不另计销，不能反复开新单 |
| D29 | 开单类型 | 选择销售开单/退货开单 | 退货界面及正式图片明确类型，不当普通正向销售 | 退货仅老板，云端校验 |
| D30 | 原销售单及原商品行 | 退货先选原单，再选实际退回商品 | 引用原冻结版本、单位及成交价，显示剩余可退量 | 允许部分商品退回，累计不超原销售数量 |
| D31 | 更正已确认单 | 老板修正客户、数量或价格并确认 | 原版本和修正版本关联，冲回旧销售再记正确；非零更正价用于后单且校验价版本，0价例外；打印绑定各自版本 | 仅老板，重试不多冲回或多计 |

## 二 客户和商品管理

| 字段编号 | 字段或按钮 | 建议处理 | 人工需确认 |
| --- | --- | --- | --- |
| M01 | 客户编号 | 系统生成稳定编号，后台查重 | 是否显示/允许维护自定义外部编号 |
| M02 | 正式客户名 | 不与习惯叫法混填；重名给区分信息 | 重名及必填长度 |
| M03 | 联系人和电话 | 保存客户联系方式，不参与自动授权转发身份 | 必填性与展示权限 |
| M04 | 送货地址 | 保存默认地址，单据按冻结内容展示 | 本单临时地址如何保留 |
| M05 | 客户备注 | 保存经营备注；不当模型指令执行 | 长度和显示范围 |
| M06 | 客户别名 | 正式名称外另建叫法映射，保留来源和作用范围 | 是否即时生效/冲突怎样确认 |
| M07 | 商品与包装维护 | SKU、名称、规格、口味、合法单位、每箱瓶数 | 新增/停用权限与更正包装方式 |
| M08 | 客户调价加减按钮 | 明示＋1元/－1元，保存才生效，历史价保留 | 步长已确认1元；按钮不开放负价 |
| M11 | 小恢复按钮 | 展示最近调价前有效价，点击恢复并记新事件 | 无旧价或价格版本已变时明确提示；不删除历史、不改冻结订单 |
| M09 | 客户资料导出 | 导出范围明确，字段与筛选可选 | 首期是否需要、格式及权限 |
| M10 | 历史订单与价格 | 查冻结历史和价源，不随主档当前值改写 | 搜索筛选和显示项 |

## 三 费用补回后续字段

| 字段编号 | 截图字段 | 后续建议怎样处理 | 不应产生的结果 |
| --- | --- | --- | --- |
| E01 | 日期、厂家/品牌、政策 | 转发明确搭赠自动入数量账，按商品关联品牌，政策标当月搭赠；不记金额 | 不当销售确认，不扩出纳 |
| E02 | 业务员与经办人 | 业务员关联负责门店后自动对应；经办人来自当前管理身份 | 不创建员工管理账号，不自动启用业绩统计 |
| E03 | 客户、关联送货单 | 关联稳定客户/订单，缺送货单允许按最终规则补 | 不创建重复销售单 |
| E04 | 代搭赠SKU、单位、数量 | 每商品按原单位记数量及剩余量 | 不扩成现金收款/出纳 |
| E05 | 发生凭证/归还凭证 | 私有照片按记录归属、查看、补充 | 上传失败不报保存成功 |
| E06 | 补回日期和数量 | 跨多家客户多选明细，逐条实际数量，防超剩余与重复保存 | 不默认全部补齐，不混单位 |
| E07 | 厂家/客户/业务员/状态/日期筛选 | 查询而非更改业务 | 不因筛选改变台账 |

## 四 账号与运维按钮

| 字段编号 | 字段或按钮 | 建议处理 | 关键异常 |
| --- | --- | --- | --- |
| S01 | 登录账号和密码 | 当前一台授权手机长期保持登录，不日常到期强制重登 | 长期会话可撤销，不能凭密码绕过单设备授权 |
| S02 | 修改密码 | 授权手机系统锁屏认证后设置新密码 | 认证取消/失败不改，不读取或上传锁屏密码 |
| S03 | 退出/换机设备 | 转移时服务端使旧设备失效，仅一台有效 | 不能只隐藏前端按钮 |
| S04 | 账号恢复 | 当前手机锁屏认证改密，正常换机旧手机扫码；丢失/损坏通过预绑定手机号验证恢复新设备 | 成功后旧设备授权和会话失效；任意输入手机号不算验证，服务与丢号例外另落实 |
| S05 | 添加转单人 | 先登记个人微信号，再核对实际平台身份完成授权 | 手填号不能单独证明来源，同名不覆盖 |
| S06 | 设备配对与撤销 | 人工核设备名、能力、限时配对 | 旧设备撤销后不能继续领任务 |
| S07 | 提醒开关和试听 | 可试听前台声音，原生锁屏另测 | 试听成功不等锁屏必达 |
| S08 | 打印刷新 | 只查询任务和设备状态 | 刷新不触发打印 |
| S09 | 打印人已出纸/未出纸 | 留确认人、时间和任务尝试；显示可读取的缺纸/卡纸反馈 | 无反馈保留未知；提交队列不当已出纸 |
| S10 | 校准左右上下偏移 | 使用非业务校准单，保存设备/模板版本 | 不改订单、不产生销售 |
| S11 | 开始自检 | 查云、设备、微信、打印、手机权限 | 不自动补打或更改价 |
| S12 | 操作日志查询 | 按用户意见删除该界面 | 保留后台必要留痕，不据此删除数据 |
| S13 | 训练/评测/人工启用/回退 | 纠错自动收集并自动训练，显示真实产物与独立评测，管理人明确启用才替换生产模型 | 未人工启用不得自动上线；评测失败维持现有模型，日志不等训练完成 |
| S14 | 功能制作进度 | 显示每项审核/开发/验收与阻塞 | 不以旧源码存在自动标100% |
| S15 | 员工姓名和登录邮箱 | 移除员工账号相关界面 | 转单登记不创建员工管理账号 |
| S16 | 员工角色及邀请员工 | 按用户意见移除 | 当前一个管理人使用 |
| S17 | 内部员工选择 | 按用户意见移除，改为转单人个人微信号登记 | 来源登记与APP管理账号分开 |
| S18 | external_userid或openid | 由可信来源获取并核对身份类型 | 不用姓名代替平台ID，不混不同应用ID |
| S19 | 客服显示名与安全绑定 | 删除客服侧显示名称，保留经验证来源与登记微信号的绑定 | 同名不覆盖，重复绑定须提示 |
| S20 | 店内识别打印设备名 | 给设备易识别名称，同时保存稳定设备ID | 名称变更不应产生新设备凭证 |
| S21 | 识别订单和打印配送单能力勾选 | 明确该设备可以领取哪类任务 | 未授予打印能力不能接纸质任务 |
| S22 | 配对有效期和生成设备连接码 | 明示期限与一次使用，生成后等待指定设备连接 | 过期或已用码拒绝，不泄露长期设备密钥 |
| S23 | AI混合识别旧启用按钮 | 改为识别就绪、模型版本和配置状态的建议 | 不因按钮亮起就认定模型可用 |
| S24 | 企业微信收取旧启用按钮 | 维持正式收单启用，删除开关配置行；健康状态另显示 | 离线故障真实提示，不扩个人群采集 |
| S25 | 打印任务手动触发旧开关 | 重新说明纸质确认后自动入队，设备异常另处理 | 不把旧开关当静默不打印理由 |
| S26 | 纸型模板和方向 | 固定130×190毫米文博预印纸，必须输出单子总合计 | 坐标、数量列及抵扣呈现实纸核对 |
| S27 | 每页可用行数 | 按实纸校准，超行走已确认的续页规则 | 不沿用旧截图13行作为新已验收行数 |
| S28 | 左右上下偏移及加减按钮 | 显示毫米和正负方向，调整后只影响套打定位 | 不能改变订单数量价格金额 |
| S29 | 打开校准单 | 使用非业务校准内容试印 | 不生成销售、不是重打真实单 |
| S30 | 直接查看校准单 | 预览变量层与位置，必要时与纸张参照对比 | 预览不等于实纸已对齐 |
| S31 | 保存偏移 | 保存设备、模板、版本和操作者 | 失败时维持旧有效参数，不误报成功 |
| S32 | 操作日志关键词/类型/内容筛选 | 随操作记录界面一并移除 | 不删除后台确认与补打证据 |
| S33 | 旧手机扫码授权新设备 | 正常换机由当前手机系统认证后明确转移，旧权限失效 | 仅一台授权，转移防重放；丢失/损坏改走S04手机号验证恢复 |
| S34 | 模型选择 | 参考旧模型，按Jetson内存、系统及业务样本实测选择 | 不未经验证锁死具体模型名 |

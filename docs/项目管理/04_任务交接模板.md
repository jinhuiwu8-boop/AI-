# 任务交接模板

## 派发

- 任务ID和名称：
- 责任工作口及实际执行代理：
- 对应正式规则/P页面/旧评估条目：
- 前置任务及合同版本：
- 输入/输出和错误状态：
- 允许修改的具体文件：
- 只读参考文件/禁止修改的共享文件：
- 已授权环境与操作范围：
- 本任务完成条件及应交证据：
- 未填参数与应先解决的问题：

## 回交

- 源码版本/本地提交/文件摘要：
- 实际变更文件：
- 实际验证环境与命令：
- 成功/失败/未运行的检查：
- 证据文件及对应版本：
- 与其他模块是否真实联调：
- 是否有真机/实纸/模型产物证据：
- 遗留问题、影响和下一步：
- 请求进入的下一阶段：

## 独立核验和登记

- A07核验范围与结论：
- ROOT整合决定及未通过原因：
- 台账更新人、日期、阶段与证据：
- 依赖方需要同步的变动：
- 是否属于待用户确认版本：
- 用户版本确认记录及Git上传结果：

不能把空栏理解为通过；检查未运行应明确写未运行。没有授权时不执行生产、真实数据、真实训练或打印来补证据。
